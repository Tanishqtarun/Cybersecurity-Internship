# Project 04 - Incident Response and Log Analysis

## Overview

This project demonstrates the analysis of Linux authentication logs to identify suspicious activities and classify a cybersecurity incident.

## Objectives

- Analyze authentication logs
- Detect suspicious login attempts
- Identify Indicators of Compromise (IoCs)
- Classify the incident
- Recommend security improvements

- Logs
- Report
- Evidence

- Log Analysis
