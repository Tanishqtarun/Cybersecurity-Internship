# Project Write-up

## What was hardest to build?
The most challenging part was designing the framework so that different reconnaissance tasks could run independently while failures such as DNS timeouts, unavailable RDAP data, or inaccessible web resources did not stop the complete run.

## What I learned
I learned how reconnaissance combines several public information sources into one structured view of a web target. I also learned the importance of modular code, error handling, and generating reports that are useful to a client rather than only printing raw command output.
